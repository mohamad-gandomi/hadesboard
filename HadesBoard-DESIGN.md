# HadesBoard --- Design System & Website Plan

## Brand

Name: HadesBoard

Persian name: هادس بورد

Position: Persian Web Design & Development Studio

Personality: - Friendly - Personal - Minimal - Technical - Premium

Audience: - Startups - B2B companies - Premium brands

Main promise: Design and develop digital experiences that are beautiful,
useful, technically strong, and connected to business goals.

------------------------------------------------------------------------

# References

Primary inspiration:

## Iran Designer

Take inspiration from: - editorial layout - strong Persian typography -
whitespace - design-focused storytelling - clear UX structure

## Chenar Khayyam

Take inspiration from: - trust building - process explanation -
technical confidence - conversion flow - project/result presentation

Do not copy: - exact layouts - colors - identity elements

------------------------------------------------------------------------

# Visual Direction

Style:

Minimal + Technical + Premium

The website should feel like: - a thoughtful studio - a modern product
company - a skilled development partner

Avoid: - generic agency templates - huge icon grids - fake statistics -
excessive gradients - unnecessary animations

------------------------------------------------------------------------

# Technical Stack

Framework: Next.js App Router

Language: TypeScript

Styling: Tailwind CSS + CSS Variables

Rendering: Static marketing website

Architecture: Server Components by default

Language: Persian only

Direction: RTL first

Font: Local Ravi font

------------------------------------------------------------------------

# Color System

Primary background: Warm cream

Text: Warm near-black

Accent: Electric cobalt blue

Suggested:

Canvas: #f5f3ed Ink: #1c1c18 Body: #57564f Accent: #3157d5

Rules: - Accent is used rarely. - No multiple competing colors. - Use
borders and spacing instead of shadows.

------------------------------------------------------------------------

# Typography

Font: Ravi

Use local @font-face.

Typography: - Large Persian headlines - Comfortable Persian line
height - Regular/medium weights preferred - Avoid heavy bold everywhere

------------------------------------------------------------------------

# HadesBoard Visual Language

The brand identity comes from the word "Board".

Use subtle system elements:

HB / 001 PROJECT 03 STATUS: LIVE TYPE: WEB

Possible motifs: - grids - coordinates - interface labels - thin guide
lines - browser frames

Keep them subtle.

# Motion

Moderate.

Allowed: - reveal animations - hover effects - project image movement -
subtle grid animation

Avoid: - scroll hijacking - heavy parallax - long loaders

------------------------------------------------------------------------

# Development Rules

-   Build design system first.
-   Then homepage.
-   Then inner pages.
-   Keep components reusable.
-   Keep content in data files.
-   Do not invent business claims.

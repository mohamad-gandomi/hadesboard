# HadesBoard AGENTS.md

## Identity

This project is HadesBoard.

The canonical Persian brand name is هادس بورد.

A Persian RTL web design and development studio.

## Design Rules

-   Read DESIGN.md before making design decisions.
-   Style direction: minimal + technical + premium.
-   Do not create generic agency UI.
-   Use whitespace intentionally.
-   Prefer typography and layout over decoration.

## Content Rules

-   Never invent:
    -   clients
    -   awards
    -   statistics
    -   testimonials
    -   results

Use placeholders when information is missing.

## Technical Rules

-   Next.js App Router.
-   TypeScript.
-   Tailwind CSS.
-   CSS variables for design tokens.
-   Server Components by default.
-   Add Client Components only when required.

## Language

-   Persian only.
-   RTL first.
-   Use Ravi local font.
-   Always write the Persian brand name as هادس بورد.

## Quality

-   Mobile first.
-   Accessible.
-   Fast.
-   SEO friendly.
-   Avoid unnecessary dependencies.

## Component Rules

-   Keep components reusable.
-   Avoid giant components.
-   Keep repeated data in data files.
-   Maintain consistency with DESIGN.md.
